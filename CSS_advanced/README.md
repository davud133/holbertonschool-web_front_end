# Advanced CSS

This directory contains my solutions for the Holberton School project
**"Advanced CSS"**.

The goal of this project is to practice CSS fundamentals and advanced styling
techniques, including variables, layout, grid systems, pseudo-classes,
transitions, transforms, gradients, browser consistency, and reusable design
patterns.

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`, `VSCode`, `Atom`
- All files will be interpreted on Chrome (version 78.x)
- All files must end with a new line
- All files must start with a comment describing the task
- A `README.md` file at the root of this project folder is mandatory
- Your code should be W3C compliant and validate with W3C-Validator
